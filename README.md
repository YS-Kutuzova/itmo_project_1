# ITMO first project - Flights programme

Проект предназначен для для работы с данными аэропортов, авиакомпаний и маршрутов,
содержащимися в базе данных. 
Он позволяет:  
- Загружать данные из CSV/(JSON-исходный формат).  
- Работать с данными напрямую из базы данных. 
- Просматривать данные авиаперелетов.  
- Находить рейсы по городу вылета.
- Находить рейсы по авиалинии.

## Установка  
Перед началом работы убедитесь, что на вашем компьютере установлено следующее программное обеспечение:
Python 3.8 или выше
PostgreSQL
pgAdmin 4: Поставляется вместе с установщиком PostgreSQL.

1. Клонируйте репозиторий:  
   git clone https://github.com/YS-Kutuzova/itmo_project_1.git
   
2. Настройка Python окружения
Перейдите в папку проекта:
   cd itmo_project_1  
Создайте и активируйте виртуальное окружение: 
   python -m venv .venv  
   source .venv/bin/activate  # Linux/macOS  
   .\.venv\Scripts\activate   # Windows   
Установите зависимости:
   pip install -r requirements.txt 
   
3. Создание базы данных:
Запустите pgAdmin и подключитесь к вашему серверу PostgreSQL.
Создайте новую базу данных с именем FlightsPyProject.
Можно использовать следующий SQL-запрос:
sql
CREATE DATABASE FlightsPyProject;

4. Подготовка исходных данных
Поместите ваши исходные JSON-файлы (например, airline.json, airports.json, routes.json) в папку с проектом.

5. Конвертация JSON в CSV
Запустите скрипты Python для преобразования данных. Выполняйте команды в терминале, находясь в директории проекта.
python import_airline.py
python import_airports.py
python import_routes.py
Результат: В папке проекта появятся новые CSV-файлы (например, airline.csv, airports.csv, routes.csv).

6. Создание таблиц в базе данных
Вернитесь в pgAdmin и откройте окно запроса к базе данных FlightsPyProject.
Создайте таблицы: Последовательно выполните SQL-скрипты из файлов:
create_table_airports.sql
create_table_airline.sql
create_table_routes.sql
!Необходимо изменить путь на ваш, в данных запросах указан путь-пример на расположение файлов!

7. Импорт CSV-данных в таблицы
Оставаясь в окне запроса pgAdmin, выполните команды импорта для каждой таблицы.
Импортируйте данные: Выполните SQL-запросы, аналогичные приведенным ниже. Убедитесь, что вы указали правильный абсолютный путь к вашим CSV-файлам.

Импорт аэропортов (выполните запрос из import_csv_airports.sql или используйте):
sql
COPY airports FROM 'C:/путь/к/вашему/проекту/airports.csv' DELIMITER ',' CSV HEADER;
Импорт авиакомпаний (выполните запрос из import_csv_airline.sql или используйте):
sql
COPY airline FROM 'C:/путь/к/вашему/проекту/airline.csv' DELIMITER ',' CSV HEADER;
Импорт маршрутов (выполните запрос из import_csv_routes.sql или используйте):
sql
COPY routes FROM 'C:/путь/к/вашему/проекту/routes.csv' DELIMITER ',' CSV HEADER;

8. Настройка подключения и запуск приложения
Перед запуском основного скрипта необходимо указать параметры для подключения к вашей базе данных.
Откройте файл Menu_and_def.py в текстовом редакторе.
Найдите секцию с параметрами подключения (например, строку с psycopg2.connect).
Замените данные для входа на свои!!!

9. Запустите основное приложение: После настройки подключения выполните в терминале:
python Menu_and_def.py
